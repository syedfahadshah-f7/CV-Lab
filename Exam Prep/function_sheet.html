CV Lab Function Sheet

Every function from Labs 01-06 with parameters, return values and the trap to avoid. Type to filter.

Top traps:
  • img.shape = (h, w, c) but dsize in resize / warp / VideoWriter = (w, h). Points are (x, y); indexing is img[y, x].
  • OpenCV = BGR. Use cv2.cvtColor(img, cv2.COLOR_BGR2RGB) before plt.imshow; gray needs cmap='gray'.
  • imread returns None on a bad path. threshold returns 2 values; adaptiveThreshold returns 1.
  • Kernel sizes (GaussianBlur, medianBlur, blockSize) must be odd. uint8 math wraps: convert to float or use cv2.add (saturates).
  • Hough functions return None when nothing is found. HoughCircles shape is (1, N, 3).
